# Отчёт по лабораторной работе №2

## Цель

Создан экран на Jetpack Compose, демонстрирующий управление текстовыми
элементами, кнопками, состоянием и компоновкой без XML-разметки.

## Реализация

Основной код находится в [Lab2Screen.kt](../app/src/main/java/com/example/puzzle/Lab2Screen.kt).
Экран доступен из общего меню приложения по кнопке `Laboratory 2`.

Использованы следующие состояния Compose:

- `firstLabelAlignment` — положение «Метка 1»: слева, по центру, справа;
- `colorOffset` — общий сдвиг цветов меток в цикле красный → зелёный → жёлтый;
- `fontSizes` — отдельный размер шрифта каждой метки;
- `isHorizontal` — переключатель `Column`/`Row`;
- `spacing` — расстояние между метками.

Все значения хранятся через `rememberSaveable`, поэтому экран восстанавливает
состояние при пересоздании Activity.

## Выбранные параметры

| Параметр | Значения |
|---|---|
| Начальное расположение | вертикальное (`Column`) |
| Начальные цвета | красный, зелёный, жёлтый |
| Начальные размеры | 20sp, 22sp, 24sp |
| Максимальные размеры | 28sp, 30sp, 32sp |
| Шаг увеличения | 2sp |
| Начальный интервал | 8dp |
| Шаг интервала | 8dp |
| Максимальный интервал | 40dp |

После достижения максимальных размеров всех трёх меток кнопка `Change Font
Size` становится неактивной. При горизонтальном расположении используется
горизонтальная прокрутка, поэтому большие интервалы не обрезают содержимое.

## Соответствие компонентов

| Задача | Compose-решение |
|---|---|
| Текстовая метка | `Text` |
| Вертикальная компоновка | `Column` |
| Горизонтальная компоновка | `Row` |
| Положение первой метки | `Box` и `Alignment` |
| Цвет текста | `Text(color = ...)` |
| Размер текста | `Text(fontSize = ...)` |
| Интервал | `Arrangement.spacedBy(...)` |
| Неактивная кнопка | `Button(enabled = false)` |

## Проверка

На эмуляторе `Pixel_10a` проверены:

1. Отображение трёх меток и пяти кнопок.
2. Циклическое перемещение «Метка 1».
3. Циклическая смена цветов всех меток.
4. Увеличение шрифта с индивидуальными ограничениями.
5. Переключение вертикальной и горизонтальной ориентации.
6. Увеличение расстояния между метками.
7. Совместная работа всех кнопок на одном экране.

## Запуск

```bash
cd ~/AndroidStudioProjects/puzzle
emulator -avd Pixel_10a
./gradlew installDebug
adb shell am start -n com.example.puzzle/.MainActivity
```

В меню выбрать `Laboratory 2`. Кнопка Back возвращает в общее меню.
