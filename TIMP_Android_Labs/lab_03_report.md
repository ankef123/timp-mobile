# Отчёт по лабораторной работе №3

## Цель

Создан Compose-экран с четырьмя переключателями. Первые три образуют ручную
кольцевую последовательность, а четвёртый включает автоматический переход с
интервалом одна секунда.

## Реализация

Код экрана находится в [Lab3Screen.kt](../app/src/main/java/com/example/puzzle/Lab3Screen.kt).
Экран доступен из общего меню приложения по кнопке `Laboratory 3`.

Состояние экрана:

- `activeIndex` — активный шаг от 0 до 2;
- `switchCount` — текущее число ручных переключателей;
- `autoMode` — состояние автоматического режима;
- `isStarted` — находится ли экран в активном состоянии Activity.

Состояния `checked` и `enabled` первых трёх переключателей вычисляются из
`activeIndex` и `autoMode`. В начале активен и доступен только переключатель 1,
а переключатели 2 и 3 выключены и недоступны.

При нажатии доступного переключателя выполняется:

```kotlin
activeIndex = (activeIndex + 1) % 3
```

Таким образом, последовательность получается `1 → 2 → 3 → 1`.

После полного ручного или автоматического цикла количество ручных
переключателей увеличивается на три, если для них остаётся место на экране:

```text
1 → 2 → 3 → 1 → 2 → 3 → 4 → 5 → 6 → 1
```

Дальнейшие циклы могут добавить переключатели 7–9 и далее до рассчитанного
предела. Предел определяется доступной высотой экрана, с сохранением числа
переключателей кратным трём. При нехватке места дополнительные группы больше
не появляются; интерфейс дополнительно разрешает прокрутку содержимого.

## Автоматический режим

Четвёртый переключатель управляет `autoMode`. При его включении запускается
единственный `LaunchedEffect`, внутри которого используется корутина:

```kotlin
LaunchedEffect(autoMode, isStarted) {
    if (autoMode && isStarted) {
        while (true) {
            delay(1_000)
            activeIndex = (activeIndex + 1) % 3
        }
    }
}
```

При выключении `autoMode` или уходе Activity в фон ключ
`LaunchedEffect` изменяется, и предыдущая корутина автоматически отменяется.
`Thread.sleep()` не используется, поэтому главный поток не блокируется.

Во время автоматического режима переключатели 1–3 недоступны, чтобы ручные
действия не конкурировали с таймером. При повторном включении автоматический
цикл продолжает работу с текущего шага. При возврате приложения из фона
таймер запускается снова только после `ON_START`.

## Проверка

На эмуляторе `Pixel_10a` проверены:

1. Начальное состояние: включён только шаг 1.
2. Ручная последовательность `1 → 2 → 3 → 1`.
3. Включение четвёртого переключателя.
4. Автоматическую смену шага примерно раз в секунду.
5. Остановку переходов после выключения четвёртого переключателя.
6. Недоступность ручных переключателей в автоматическом режиме.
7. Отмену фоновой корутины при уходе Activity из активного состояния.

```bash

./gradlew installDebug
adb shell am start -n com.example.puzzle/.MainActivity
```
